What it does

One line in, a glance out.

Every card below is dropped by the same engine as the one above. Hit play on any of them.

TerminalShell

Up to three cards at once.

Cards that arrive while one is showing stack below it. Chain, the default, drops each new card out of the bottom of the last one. Push drops it out of the notch once the others have moved down. A fourth waits until there is room.

This is the engine, not a picture: DripCore's CardStack, the same code the Mac app runs, places every card here, times it, and stops every countdown while your pointer is on a card. Pick a mode to play it.

How this page works

Not a video. The actual code.

DripCore, drip's engine, is compiled from the same Swift sources to WebAssembly and loaded by this page. It parses each command line, resolves the card, wraps the text and springs the drop out of the notch. The page only paints what it computes. Turn on the engine readout to watch the numbers.

Real drip

  • The command line, parsed by swift-argument-parser, with drip's own errors and --help
  • Presets, flags and your config.toml
  • drip run's title and timing, drip hook's payload reading
  • Text wrapping, every size, every spring, and the liquid outline traced by marching squares
  • Stacks of up to three cards, chained or pushed, and cards replaced in place: DripCore's CardStack places, times and springs them

Drawn by this page

  • The paint: icons stand in for SF Symbols
  • Fonts are your browser's system font
  • Commands that drip run wraps are pretend, and timed for real
  • The crossfade when a card is replaced in place, on drip's own timings
  • No sound

Only on a Mac

  • Other positions and styles: every card here is a notch card
  • History and missed cards
  • The system sounds
Install

A minute to your first drip.

Homebrew builds drip from source with the Command Line Tools it already needs, in about a minute. Xcode is not needed.

$ brew install jrnxf/tap/drip
$ drip ok "drip works"
$ drip run -- make test # then wrap anything
