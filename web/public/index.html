Wrap a command

drip runs it, times it and shows how it went: green on exit 0, red with the exit code otherwise.

$ drip run make test

Update in place

Cards with the same --id replace each other. The card on screen springs to the new card's size.

$ drip ok "Deployed" --id deploy

Open something from it

--open puts a button on the card. A click opens a URL, a file or an app.

$ drip ok "Report ready" --open ./report.html --button "View report"

Hear from coding agents

A hook from a recipe names the project and what the agent needs, then says when it has finished.

# in ~/.claude/settings.json, from a recipe
$ drip hook claude

Ask, then act

--yes and --no wait for a click. drip exits 0 on yes, so && runs the next step only then. Answer it here.

$ drip ok "Merge drip #23?" --yes Merge --no Later && gh pr merge 23

Your own presets

Icons, colors, sounds and timing go in ~/.config/drip/config.toml. Here, a deploy preset.

# ~/.config/drip/config.toml
[preset.deploy]
icon = "paperplane.fill"

$ drip deploy "Shipped to prod"

Three at once

Cards that arrive together stack, each out of the last. Past three, they wait in a drop that counts them.

$ drip ok   "Build finished"
$ drip warn "Disk almost full"
$ drip fail "Deploy failed"
$ drip info "Backup done"
$ drip ok   "Release 1.4 is out"

02 / details

small, and it stays out of the way.

macOS 13 or newer. A notch is optional: without one, cards come from the top edge. Cards wait while the screen is locked.

kindsok, warn, fail, info, and presets from your config
texta title of up to 2 lines and a detail of up to 3. Pipe text in and the first line is the title
time4.5 s by default. --seconds takes 0.5 to 60. --stay keeps it until clicked
buttons--open opens a URL or a file. --yes / --no ask, then exit 0 or 1
agentsClaude Code, Codex and Gemini CLI, through a recipe's hook
quietdrip pause 30m for a meeting. drip history --missed for what you missed
