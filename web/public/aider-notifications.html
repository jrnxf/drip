Aider notifications on Mac, from the notch.

Start Aider with --notifications --notifications-command set to a drip command, and a card from your Mac's notch shows when Aider is done and waits for you. Install drip first with brew install jrnxf/tap/drip.

brew install jrnxf/tap/drip

Aider has no hooks, so this recipe uses its notification command and installs nothing in drip. Start Aider like this:

aider --notifications --notifications-command 'drip ok "$(basename "$PWD") is done" --id "aider:$PWD" --icon terminal.fill'

Or, in .aider.conf.yml: notifications: true, and notifications-command: with the same command.

drip is a free, open-source macOS CLI that shows scriptable notification cards from the MacBook notch, for builds, deploys and coding agents like Claude Code, Codex and Gemini CLI.

How it works

  1. Aider runs a command when it waits. --notifications-command is that command, and --notifications turns the feature on.
  2. The command is drip. drip ok shows a green card titled with the project's folder name and is done.
  3. One card per project. The id is aider:$PWD, so a new card from the same project replaces its last one instead of queueing behind it.
  4. Change the look. Change the title, the icon or the card options. drip --help lists them.

FAQ

Does Aider need hooks for this?

No. Aider has no hooks, so the recipe uses its notification command. Nothing is installed in drip, and you change no file unless you want the command in .aider.conf.yml.

How do I make it permanent?

Put it in .aider.conf.yml: notifications: true, and notifications-command: with the same command as on the command line.

What if I run Aider in two projects at once?

Each project gets its own card. The id is aider:$PWD, so only a new card from the same folder replaces the last one.

Can the card ask for permission like Claude Code's?

No. The recipe shows one card, for when Aider is done and waits for you. For a tool without hooks, you can wrap what it runs in drip run, or call drip from the tool's own commands.
