drip vs Notchi, terminal-notifier vs ntfy and more.

drip is a command-line tool that draws its own card from the notch for any command or coding agent, with no Notifications permission. Notch apps such as Notchi, Coucou, notch-so-good and Vibe Island set up agent hooks for you. terminal-notifier, osascript and alerter post to Notification Center. noti and ntfy send to other services and phones. Checked on Sunday 15 November 2026.

drip ok "build finished"                                        # drip
terminal-notifier -title build -message finished                # terminal-notifier
osascript -e 'display notification "finished" with title "build"'  # osascript
alerter --title build --message finished                        # alerter
curl -d "build finished" ntfy.sh/mytopic                        # ntfy

Which to pick

  • drip if you want to see at a glance how a build, deploy or agent turn went, to script what a card does, or to time any command with drip run.
  • A notch app for coding agents (Notchi, Coucou, notch-so-good or Vibe Island) if you only want agent activity in the notch and want the app to set up the hooks for you. They are built for that, and drip asks you to paste a snippet.
  • Vibe Island, Coucou or notch-so-good if you want Allow and Deny buttons in the notch without writing a recipe. drip offers them only for short one-line shell commands, from Claude Code and Codex.
  • ntfy if you want a push on your phone, or an alert from a machine that is not your Mac.
  • terminal-notifier if you want notifications that follow Focus and stay in Notification Center's list.
  • osascript if you can install nothing, since it is already on every Mac.
  • alerter if a script needs a typed reply or a choice from a dropdown in a system alert.
  • noti if you want one command that can send to Slack, Telegram or other services. Check that it still suits you, as its GitHub copy is archived.
  • ccnotify if you want a quick Claude Code Stop hook that posts to Discord or ntfy.

A script can call more than one of these tools.

FAQ

Is drip a notch app like Notchi?

Partly. drip also draws from the notch, but it is a command-line tool, not an app that sets itself up around your agents. It shows a card only when a command or a hook calls it, and it does not install hooks for you. Notchi, Coucou, notch-so-good and Vibe Island are apps that install or configure agent hooks themselves.

Does drip replace terminal-notifier?

For alerts about builds, deploys, tests and coding agents, yes. If you want notifications to wait in Notification Center's list and follow Focus, terminal-notifier does that and drip does not.

Does drip need a Mac with a notch?

No. On a Mac without a notch, the card grows out of the top edge of the screen.

Can drip send a push to my phone?

No. drip shows a card on your Mac. For a push to a phone, use ntfy.

Why is drip not in Notification Center?

So it needs no Notifications permission and can show at the notch, where a glance finds it. The cost is that it does not follow Focus; drip pause holds cards for a while instead.

Can I use drip and terminal-notifier together?

Yes. They do not touch each other's settings, so a script can call either.
