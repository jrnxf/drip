# Security policy

## Reporting a vulnerability

Please report a vulnerability in private. Do not open a public issue.

1. Open the [Security tab](https://github.com/jrnxf/drip/security) of the repository.
2. Choose Advisories, then "Report a vulnerability". The direct link is
   <https://github.com/jrnxf/drip/security/advisories/new>.
3. Say what you found, which version of drip you ran and how to reproduce it.

Only the latest release gets fixes.
